# Data Dictionary

**Analysis period:** 2021-01-01 through 2025-12-31.

This document combines source-grounded definitions with metadata observed in the project datasets. 
## Source references

- Independent Electricity System Operator (IESO), *Hourly Electricity Consumption Data by Forward Sortation Area – Report Description*.
- Environment and Climate Change Canada (ECCC), *Historical Climate Data* and associated technical documentation.
- Project preprocessing and calendar-generation scripts in this repository.
