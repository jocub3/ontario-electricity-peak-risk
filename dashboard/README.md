# Ontario Electricity Demand & Peak-Risk Decision Support Application

Lightweight public Streamlit application for the Ontario Electricity Demand
Forecasting and Peak-Risk Decision Support capstone project.

## Public deployment architecture

This repository does **not** contain the large trained model bundle.
The app reads precomputed, validated Parquet/JSON outputs generated by the
full academic pipeline.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run dashboard/app.py
```

## Streamlit Community Cloud

Use:

- Repository: this repository
- Branch: `main`
- Entrypoint: `dashboard/app.py`

## Important interpretation boundary

Weather-sensitivity scenarios perturb forecast-origin temperature in this Model.
They describe model sensitivity, not causal weather effects.
