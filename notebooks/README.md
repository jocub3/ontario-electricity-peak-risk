# Notebooks

Use numbered notebook names and keep each notebook focused.

Example:

```text
01_data_exploration/01_01_demand_quality_check.ipynb
02_forecasting/02_01_sarimax_experiment.ipynb
03_peak_risk/03_01_logistic_regression.ipynb
04_evaluation/04_01_model_comparison.ipynb
```

Reusable functions should be moved from notebooks into `src/`.
